# كون الفيزياء السعيد — Happy Physics Universe

**Learn Physics. Play the Impossible.**

منصة ألعاب تعليمية في المتصفح فيها 6 ألعاب فيزياء، كل لعبة = درس، وكل مرحلة فيها معادلات حية وقياسات ومصطلحات وسؤال سريع بعد الفوز.

| اللعبة | الدرس | الفيزياء داخل اللعبة |
|---|---|---|
| Happy Bird: Sky Mission | حركة المقذوفات | x = v₀cosθ·t ، R = v₀² sin2θ / g ، الأرض/القمر/المريخ |
| Rescue the King: Water Kingdom | ضغط الموائع والطفو | P = ρgh ، تورشيلّي ، الأواني المستطرقة ، أرخميدس |
| Magnet Hero: Power Factory | الحث الكهرومغناطيسي | ε = −NΔΦ/Δt ، قانون لنز ، المولّد NBAω |
| Circuit Quest: Light the City | الدوائر وقانون أوم | V = IR ، توالي/توازي ، قصر الدائرة (حلّال دوائر حقيقي) |
| Light Maze: Laser Escape | انعكاس الضوء وانكساره | θi = θr ، قانون سنل ، الانعكاس الكلي الداخلي |
| Energy Rider | حفظ الطاقة الميكانيكية | ½mv² + mgh ، شرط الحلقة h ≥ 2.5r ، الاحتكاك |

## التقنية
- HTML + CSS + JavaScript (ES Modules) و Canvas — **بدون أي مكتبات وبدون خطوة Build**.
- التقدّم (النجوم، البلّورات، الإنجازات، اللغة) محفوظ في `localStorage` على جهاز اللاعب، لذلك **لا يحتاج المشروع قاعدة بيانات**.
- عربي/إنجليزي مع دعم كامل للاتجاه RTL.

## هيكل المشروع
```
index.html          الصفحة الرئيسية
css/style.css       التصميم
js/config.js        عناوين الألعاب والدروس والصف الدراسي والإنجازات (عدّلها من هنا)
js/i18n.js          نصوص الواجهة بالعربي والإنجليزي
js/main.js          الشاشات، المراحل، النتائج، الأسئلة، الإنجازات
js/engine.js        محرك الرسم (عالم 1000×600 يتمدد على أي شاشة)
js/games/*.js       الألعاب الست (المراحل والأسئلة والمعادلات داخل كل ملف)
vercel.json         إعدادات Vercel
```

## التشغيل على جهازك
اضغط مرتين على `start-server.bat`: يشغّل السيرفر ويفتح اللعبة في المتصفح.
أو يدويًا (المتصفح يمنع ES Modules من `file://`):
```bash
py -m http.server 5173
```
ثم افتح http://localhost:5173

## الرفع على رابط
المشروع موقع ثابت (Static) لا يحتاج سيرفر Node ولا قاعدة بيانات ولا أمر Build، فيعمل على أي استضافة ثابتة:

| الخيار | المناسب لـ | الخطوات |
|---|---|---|
| **GitHub + Vercel** (الموصى به) | رابط احترافي وتحديث تلقائي مع كل تعديل | ارفع الملفات على مستودع GitHub ← vercel.com/new ← Import ← Framework: `Other` ← Deploy |
| GitHub Pages | من دون حساب إضافي | Settings ← Pages ← Branch: `main` / root ← Save |
| Netlify Drop | أسرع تجربة (دقيقة واحدة بلا Git) | اسحب المجلد إلى app.netlify.com/drop |

## تعديل المحتوى
- أسماء الألعاب والدروس ووصف الصف: `js/config.js`
- المراحل والأسئلة ونص «ماذا تعلّمت؟»: مصفوفات `LEVELS` و `QUIZ` أعلى كل ملف في `js/games/`
